# Roadmap

## Initial reference release
- Versioned graph document schema and typed records.
- Evidence-backed relationships and explicit uncertainty.
- Deterministic JSON serialization and bounded query helpers.
- Python 3.10–3.12 CI and synthetic fixtures.

## Later, separately reviewed
- Adapters for the OSINT Evidence Engine and Entity Resolution contracts.
- Persistent storage adapters with transactional semantics.
- Temporal graph snapshots and change history.
- Federated graph exchange and signed provenance envelopes.

No later capability is implied by the initial release.
