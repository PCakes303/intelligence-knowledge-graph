# Contributing

Contributions must preserve the graph contract, provenance requirements, uncertainty semantics, and privacy boundaries.

1. Add positive, negative, boundary, and malformed-input tests.
2. Keep runtime dependencies in the Python standard library unless a reviewed decision authorizes otherwise.
3. Do not add real-person examples or live-source collection.
4. Document schema changes and compatibility impact.
5. Run the complete unittest suite and graph validator before submitting.

See [SECURITY.md](SECURITY.md) for reporting guidance.
